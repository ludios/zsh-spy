zsh-spy provides full JSONL-based history logging for zsh, including command start and end records, and handling of backgrounded jobs. See the block comment in zsh-spy.zsh for more info.

This is almost fully LLM-authored with various models, initially with [ChatGPT 5.2](https://ludios.org/slop/Zsh%20History%20Logging%20Setup%20-%20https%EF%BC%9A_chatgpt.com_c_696d7ba0-b5f0-8331-8678-05c83eec88a0%282%29.html) and then further refined by Fable 5 and ChatGPT 5.6 Sol (Pro).
